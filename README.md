# 🥗 SafeBite: Food Expiry Application & Inventory Manager

[![PRT 362S - Term 4 Group Project](https://img.shields.io/badge/CPUT-PRT%20362S-green.svg)](https://github.com/AidenClintonWallace/SafeBite-Backend)
[![Platform: Android (Expo/React Native)](https://img.shields.io/badge/Platform-Android-blue.svg)](https://reactnative.dev/)
[![Backend: Supabase](https://img.shields.io/badge/Backend-Supabase%20(PostgreSQL)-orange.svg)](https://supabase.com/)

SafeBite is a smart mobile application designed specifically for **Android users** in South African communities to monitor food expiration dates, reduce household food waste, track pantry inventory via barcode scanning, and flag counterfeit or unsafe food products.

## 🛠️ Tech Stack
* **Frontend:** React Native, Expo (SDK 54), Expo Router, Vector Icons.
* **Backend & Database:** Supabase (PostgreSQL relational database).
* **External API Integration:** Open Food Facts API for barcode metadata retrieval.
* **Target Platform:** Dedicated **Android Application** (built and deployed via EAS Build preview APKs).
